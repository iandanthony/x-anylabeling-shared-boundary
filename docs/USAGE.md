# 使用说明：固废区域多边形标注

适用于本扩展 1.0.5 / X-AnyLabeling 4.0.6。安装完成后使用 `python launch.py` 或本项目快捷方式启动。菜单语言不同或快捷键被自定义时，以实际菜单提示为准。

## 1. 先统一标注规则

建议先挑 5–10 张代表性图片确定类别、边界和对象划分。类别名称需要完全一致，例如“工程渣土”“装修垃圾”“拆除弃料”“林业废物”；这些是示例，请按项目最终清单使用，不要把“拆除垃圾”“建筑废料”“拆除弃料”自动当成同一类。

标注的是可见区域；一般不推断遮挡后的隐藏部分。相互分离的区域分别描绘，只有确属同一对象的分块才使用相同 Group ID。混合堆体、零星碎块、阴影和不确定区域的判断，应提前约定。

**只标感兴趣类别可以，但同一张训练图内这些类别应按项目规则完整标出。**没有标注的像素在常见语义分割导出中会成为背景；如果其中还有漏标目标，训练时可能被当成负例。局部标注用于训练时，应裁剪到完整标注范围，或让导出 / 训练流程明确生成并忽略未标区。不能仅在说明文字中写“未标”就认为训练会自动忽略。

## 2. 打开图片与保存位置

1. 文件 → 打开目录，或 **Ctrl+U**，选择图片目录。
2. 可在文件菜单启用自动保存；完成每张图仍建议 **Ctrl+S**。
3. 默认 JSON 与图片同名，例如 `001.jpg` / `001.json`；通常在图片目录，若指定了输出目录则检查对应位置。
4. 先保存一张测试图片，并用文件资源管理器确认 JSON 生成。
5. 标注过程中保持图片尺寸、文件名和路径稳定；备份原图和 JSON。

## 3. 标签窗口和 Shapes 列表

完成多边形后弹出的标签窗口：

| 字段 | 用途 | 一般固废分割怎么填 |
| --- | --- | --- |
| 顶部类别名称 | shape 的 `label`，决定类别 | 输入统一名称，确认后新名称可用于后续对象 |
| Group ID | 关联属于同一对象的多个形状 | 语义分割可留空；实例分块按对象编号 |
| Enter linking | 记录形状间关系，常用于关系 / KIE 标注 | 普通区域分割留空，不用于绑定公共边 |
| Label description | 说明备注 | 可填待复核原因；不能代替类别 |
| useDifficult | 难例标记 | 按项目约定使用；训练是否处理取决于导出器 |

修改类别可在编辑模式下对目标打开标签编辑窗口。不要只改 description 而保留错误的 label。类别应按事先约定的标准建立。

**Shapes 左侧的勾选框控制显隐。选中编辑目标应点击名称文字行。**先按 Ctrl+J，再点目标名称行；选中状态会同步到画布。本扩展的扣除按钮以该目标为准，不用靠鼠标悬停保持选择。右键点 Shapes 行用于锁定 / 解锁，不用于扣除。

## 4. 手工多边形与连续描边

### 4.1 普通多边形

按 **P**，沿可见边界逐点单击；闭合到起点或双击结束，至少三个点。输入类别确认。普通工具每个顶点需要单击一次。

按 **Ctrl+J** 进入编辑模式，选中目标后可拖动顶点。边线可拖出新增顶点，Shift 点击顶点删除单个顶点；选择整形后 Delete 删除。Ctrl+Z 撤销，Ctrl+S 保存。拖点操作对共享边自动同步的前提是已开启共边精修。

### 4.2 按住左键移动加点的画笔多边形

1. 按 **Ctrl+N / Create Brush Polygons**。
2. 在边界起点**按住左键**，沿边界移动鼠标；软件按间距自动加入顶点。
3. 松开左键暂停；把鼠标移回最后一个已画点附近，重新按住左键移动继续。松开时移动鼠标不加点，也不会误闭合。
4. 按住左键沿边界回到起点附近闭合，或松开后按 **Enter** 完成，再输入类别。
5. 编辑 → **画笔多边形点间距…**，把 **Brush Point Distance** 改为合适数值，再点击 **Save**。

1.0.5 起，**编辑 → 连续描边：按住左键才加点**默认开启。菜单切换立即生效并自动保存，重启后保留；取消勾选可恢复起点单击、随后仅移动鼠标加点的旧方式。暂停后按下左键只恢复，不插入重复顶点；应先回到末端附近继续，避免下一段接出不需要的直线。确认类别后 Ctrl+S 保存，Esc 放弃草稿。

范围 **1–200 屏幕像素**。先试 5；细节多用 3–5，一般用 8–10，平直段用 15–25。数值越小顶点越密，也更容易保留手抖。放大图片后，同样间距对应更小的原图距离；设置只影响后续加入的顶点。

**Ctrl+N 创建画笔多边形**与 **Shift+B 修改已有区域的编辑画笔**是两个工具，不要混淆。

### 4.3 误双击后关闭类别窗口

误双击会暂时结束轮廓并打开类别窗口。1.0.2 起，点窗口右上角 **×**、**Cancel** 或在弹窗内按 **Esc**，会保留所有已画顶点并回到草稿。普通多边形继续单击；Ctrl+N 默认模式回到末端，重新按住左键移动继续，取消左键开关后仅移动鼠标继续。不用重新点创建工具。

继续画完后按 **Enter** 或点回起点，确认类别，再 **Ctrl+S** 保存。草稿未确认类别时不提交、不自动裁剪；在画布按 **Esc** 才是主动放弃草稿。此前已经丢失的未保存顶点不会通过更新自动重建。

### 4.4 连续描边时缩放，避免边缘跑偏

1. Ctrl+N 启动连续描边，默认按住左键沿边界移动绘制。
2. 需要放大或缩小时，**先松开左键**，把鼠标停在想保持不动的边界位置，按住 **Ctrl** 滚动滚轮。1.0.3 会固定鼠标下的图像坐标，已有顶点坐标不变。
3. 按住 Ctrl 时暂不自动加点。缩放后松开 Ctrl，默认模式回到边界末端，重新按住左键继续；如果取消了左键开关，则实际移动鼠标恢复随鼠标描边。
4. 需要平移时，松开 Ctrl，**按住鼠标滚轮（中键）拖动**，可向上下左右移动图幅，期间不加点。
5. 松开中键后把鼠标移回最后一个已画边界点附近，**重新按住左键移动继续**。若取消左键开关，则单击左键一次恢复，再仅移动鼠标继续画。回位和恢复用的按下均不添加顶点；底部状态栏会提示操作。普通多边形中键松开后按原方式继续单击加点。

中键平移从 1.0.4 起默认生效。不按 Ctrl 滚动滚轮仍是滚动画面；按住中键拖动才是四方向平移。暂停时仍可缩放和再次中键平移，也可 Enter 完成或 Esc 放弃。空格拖动保留原有操作；连续描边建议使用中键，以便在平移后安全回位。

缩放后周围可能出现可滚动的留白，用于避免图像较小或靠近边缘时锚点被滚动条范围限制而偏移。按 **Ctrl+F** 适合窗口，或 **Ctrl+Shift+F** 适合宽度，可恢复常规视图；切换图片也会清除这个留白。无需重新启动绘制工具。

该修复针对 Ctrl+N 连续描边时的 Ctrl+滚轮；Shift+B 编辑画笔的滚轮仍调整画笔半径。若旧顶点已经跑偏，应先撤销或手工修正，更新不会重建先前错误的边界。

## 5. SAM2 辅助分割

1. **Ctrl+A** 打开 AI 面板，选 **Segment Anything 2.1 (Large)**，等待加载。静态照片选静态模型。
2. 边缘粗糙时，点 **编辑 → SAM2 细节优先（局部裁剪 + 细轮廓）**。菜单选中 / 触发后，后续预测使用该预设；旧多边形不会自动重算。
3. 在 AI 面板点击 **+Rect**，在图片上单击一个角，移动到对角再单击，包住目标及少量背景。这是 SAM 框提示；不是普通 R 矩形标注，也不需要按住鼠标拖框。
4. 点 **Point (Q)** 在目标内部加前景点；点 **Point (E)** 在误圈背景或相邻类别加背景点。边界附近的点应明确落在一侧，不要点在模糊交界线上。
5. 看每次提示后的轮廓；满意后 **F** 完成，输入类别。**B** 可清除提示重新开始。

预设开启 **TinyObj** 局部裁剪，并把轮廓简化参数设为约 **0.0003**。这有助于保留细节，但不能保证模型识别正确的类别和边缘。先缩小框的无关背景，补少量正负点，再调精细度；不要盲目增加顶点或提示点。

目标太大、材料纹理相似、阴影干扰时可分区域生成，再人工复核；需要完整独立对象时保持 Group ID 规则。若仍偏离真实边界，用拖点、Shift+B 或拉直工具修正。轮廓颗粒锯齿过多时可把精细度滑块向右调一些。

## 6. 相邻类别公共边

### 6.1 旧区域优先（默认）

保持 **编辑 → 旧区域优先：自动裁剪新多边形（共边）** 勾选。先标 A，再标 B，让 B 在交界处稍微压入 A。完成 B 的类别后，结果是 `B = B − A`，A 原样保留，两类交界按 A 的已有轮廓扣除。若有多个其他类别旧区域与 B 重叠，从 B 中扣除这些旧区域的并集。

只自动处理新多边形与其他类别旧多边形的重叠；锁定的旧多边形也作为参考，保持不变。同类和矩形不参与自动扣除。新区域完全被覆盖时移除；被切开的剩余区域保留为多个新类别多边形，沿用类别、Group ID 和描述。不能自动跨过空白缝隙。Ctrl+Z 可一次撤销该次新标注及自动裁剪。

### 6.2 手动选择参考类别

例如工程渣土 A 的边界正确，装修垃圾 B 与其重叠，应缩小 B：

1. 如果希望先保留重叠、再选择参考类别，创建 B 前关闭“旧区域优先：自动裁剪新多边形（共边）”。已有重叠可直接下一步。
2. Ctrl+J，Shapes 点击 **装修垃圾 B 的名称行**。
3. 点击“从‘装修垃圾’中扣除其他类别的重叠”。
4. 多个类别与 B 重叠时，在对话框选 **工程渣土**。

结果为 `B = B − A`；A 是参考，不被修改。被选中的对象是要缩小的对象，不是保留边界的对象。完全被覆盖会删除目标；分离的剩余区域会保留成多个同类多边形。

“以画布选中图形为准裁剪其他类别”是反方向的手动工具，执行后会裁剪其他区域；保留旧边界的日常流程使用默认自动裁剪或 Shapes 自身扣除按钮。1.0.0 曾采用新区域优先；更新后保存并重启，旧版已经裁掉的区域需通过撤销或备份恢复。

### 6.3 修改公共边，两侧一起变

1. Ctrl+J → Shapes 选中要编辑的多边形。
2. 编辑 → **共边精修：联动相邻类别**，选择本次相邻类别。
3. 拖动公共边顶点，松开后同步；或 Shift+B 左键补区域、Ctrl+左键缩小，**右键提交**。
4. 当前区域缩小，选定邻区补齐；当前区域扩大，邻区退让。
5. 完成后关闭联动，Ctrl+S 保存。

联动以开启时两侧区域的并集作为区域分配基础；适合修改两类之间的公共边。一次联动一个邻类，遇到第三类应分次选择。切换图片或撤销会结束联动；锁定形状不能作为联动对象。不要将此模式当成任意外边界补洞工具。

## 7. 同类对象与重叠

选中**需要缩小的对象**，Shapes → **从当前对象扣除同类重叠**。结果为当前对象扣除其他同类对象的并集，参考对象不变。相同且非空 Group ID 的形状作为同一对象的分块，不互相扣除；不同对象可使用不同 Group ID 或留空。

同一堆体的同类分块在语义分割掩膜中通常按并集使用；不同实例则要保留身份，按可见区域规则处理误重叠。统计面积时要用同类并集，不要直接相加导致重复计数。

## 8. 顶点过多时局部拉直

### 8.1 点起点与终点

Ctrl+J → Shapes 选中图形 → 编辑 → **拉直一段边界（点起点和终点）** → 依次点击已有顶点。保留首末点，删除沿边界**长度较短**一侧的中间点。若想明确处理另一侧，使用圈选方式。

### 8.2 自己画多边形选区

1. 选中形状，点击 **多边形圈选顶点拉直**。
2. 逐点画临时选区，圈住一段连续顶点，首末保留点也要圈入；选区可以是凹形。
3. 点回起点 / 双击 / Enter 闭合并预览：蓝点为选中顶点，橙点为首末点，橙线为新边界。
4. 确认后 **Enter** 执行。首末点保留，中间点删除。

画选区不是新标注，不弹类别窗口。Backspace 退回选区角点；Esc / 右键取消；预览后可单击新的起点重画。至少圈三个顶点；一次必须是一段连续边界，不能圈整个图形或多个分离片段。选区跨首尾索引也支持。新直线会与保留边界相交时会拒绝修改。

处理公共边前先开启共边精修，拉直提交后另一侧同步；Ctrl+Z 撤销。

## 9. 检查、保存与导出

每张图片完成后：

1. 放大检查漏标、小块、图像边缘、错误类别和公共边缝隙。
2. 检查 Shapes 类别名称、分块 Group ID、锁定状态。
3. Ctrl+S 保存，再 A / D 切换上一张 / 下一张。
4. 负样本也按项目要求保存 / 复核，避免与尚未标注混淆。
5. 备份图片和原始 JSON，再导出训练格式。

| 目标 | 常见交付 | 重点检查 |
| --- | --- | --- |
| 语义分割 | 每像素类别 MASK | 类别编号、背景 / ignore、重叠优先级、漏标 |
| 实例分割 | COCO / YOLO-Seg 等 | 每个实例范围、对象身份 / 分块规则、格式是否支持孔洞 |
| 区域面积 | 多边形 / 掩膜并集 | 同类重叠不能重复累计；实际面积需另有尺度信息 |

导出菜单和配置使用上游功能。YOLO 的 `classes.txt` 每行一个类别，顺序决定编号，定稿后保持稳定。本扩展消除重叠会实际修改原始多边形，不只改变颜色覆盖。出现孔洞时会拆成可保存的无孔多边形；导出实例格式前核对拆分后仍满足项目对象规则。
