# X-AnyLabeling 共边标注版

按[安装说明](INSTALL.md)安装后，用 `python launch.py` 或本项目快捷方式启动。以下菜单适用于 X-AnyLabeling 4.0.6 的共边扩展；SAM2 权重需在上游模型面板下载 / 配置。使用概览见[使用说明](USAGE.md)。更新源码后需要重启软件；本机快捷方式名称可能与下文示例不同。

## 调整鼠标移动自动加点的距离

保存标注并重启共边版后，点击 **编辑 → 画笔多边形点间距…**。它会直接定位到设置页的 **Brush Point Distance（画笔点间距）**，可设为 **1–200 像素**。把 25 改成 **5** 后，点击设置窗口的 **Save（保存）**；设置会立即生效，并在重启后保留。这里只调整 **Ctrl+N / Create Brush Polygons（画笔多边形）** 的鼠标移动自动加点距离。

建议细边界先试 **5 像素**，一般边界用 **8–10 像素**，较平直的边界可用 **15–25 像素**。数值越小，记录的顶点越密，也更容易记录手部抖动。单位是屏幕像素；放大图像后，同样的间距对应更小的原图距离。修改只影响之后添加的顶点，已有多边形不会重新采样。

## 怎样标相邻类别

**边缘细节不够时：**先加载 **Segment Anything 2.1 (Large)**，点顶部 **编辑 → SAM2 细节优先（局部裁剪 + 细轮廓）**。在右侧自动标注面板点 **+Rect**（SAM2 的框提示，不是顶部普通矩形工具或快捷键 R），在图片上单击框的一个角，移动鼠标后再单击对角，完成包住目标堆体和少量周边背景的框。随后点 **Point (q)** 给目标加前景点，点 **Point (e)** 给相邻类别或背景加背景点。预设会开启面板的 **TinyObj** 局部裁剪，并把多边形轮廓精细度调到 0.0003。它只影响后续 SAM2 结果；已经保存的多边形要重新分割或手工修边。框不要切掉目标，也不要框进太多无关区域。若结果出现锯齿，可把精细度滑块向右调一些。

1. 先标工程渣土。
2. 再用 SAM2 或手工多边形标装修垃圾、拆除垃圾。**新区域在交界处稍微压进旧区域一点**，不要留缝。输入类别并确认后，共边版会把重叠部分从旧类别中扣掉；新区域的边缘即为两类共用的边缘。
3. 需要继续修两类的交界时，按 **Ctrl+J** 进入编辑模式，单击右侧 **Shapes** 中**要修改的那个多边形名称**（例如“装修垃圾”，不要点勾选框）。列表点选会同步选中画布图形，不必依赖鼠标悬停。然后点顶部 **编辑 → 共边精修：联动相邻类别**。如果它接触多个类别，选择这次要联动的相邻类别（例如“工程渣土”）。
4. 按 **Shift+B** 用编辑画笔修边：左键涂抹可扩大当前类别；按住 **Ctrl** 涂抹可缩小当前类别。**右键提交画笔修改后**，相邻类别会自动退让或补上空出的区域。拖动顶点修边后松开鼠标也会同步。完成后关闭“共边精修”，按 **Ctrl+S** 保存。

**一段边界弯折过多时：**先按 **Ctrl+J**，在 Shapes 中点选要修改的多边形；如果这段是两类的公共边，先开启 **编辑 → 共边精修：联动相邻类别**。然后点 **编辑 → 拉直一段边界（点起点和终点）**，放大图像，依次点弯折段两端的**顶点圆点**。软件保留这两个顶点，删除两者之间**沿边界较短的一段**的中间顶点，并用直线连接。右键取消；操作后按 **Ctrl+Z** 可撤销。若两点相邻，或删除会使多边形少于三个顶点，则不会修改。

仅选中多边形会进入普通编辑状态，仍需点上述菜单启动端点拉直工具。选好起点后，它会高亮，底部提示点击另一个端点。SAM 轮廓其他位置已有小环时，也能局部拉直；如果新直线与其他边界相交，会提示重新选择端点并保留原标注。

## 自己画多边形选区，圈选顶点并拉直

1. 保存标注，重启桌面上的 **X-AnyLabeling（共边标注）**，让新增功能生效。
2. 按 **Ctrl+J** 进入编辑模式，在 **Shapes** 中点击要处理的多边形名称。
3. 点击 Shapes 下方的 **多边形圈选顶点拉直** 按钮，或点 **编辑 → 多边形圈选顶点拉直**。
4. 用左键逐点画出自己的多边形选区，圈住需要拉直的一段顶点，**把要保留的首末顶点也圈进去**。选区可以是凹多边形，用来避开其他边界。点回选区起点或双击结束，闭合后预览：蓝色圆点是选中的标注顶点，橙色圆点是保留的首末顶点，橙色直线是将生成的边界。
5. 确认预览后按 **Enter**，删除选中段的中间顶点，首末顶点直接连线。按 **Ctrl+Z** 可撤销，**Ctrl+S** 保存。画选区和预览不会改动标注，也不会新增类别或标注形状。

画选区时按 **Backspace** 可退回一个角点；也可以按 **Enter** 闭合并预览，再按一次 Enter 执行。预览后单击新的起点可重新画选区；右键或 **Esc** 退出工具。一次只处理当前多边形的一段连续边界，至少圈住三个标注顶点。若选区边线交叉、圈住整条轮廓、多段不连续边界，或新直线会与其他边界相交，会保留原标注并在底部提示调整选区。选中的弯折段即使比另一侧轮廓更长，也按圈选段处理。

如果是公共边，先开启 **编辑 → 共边精修：联动相邻类别**，再圈选拉直；按 Enter 提交后，相邻类别会同步补齐或退让。切换图片或撤销会结束圈选模式。

## 已有两个多边形重叠时

### 同类不同对象的重叠

保存标注并重启共边版后，Shapes 下方新增 **从当前对象扣除同类重叠** 按钮。按 **Ctrl+J**，点击**需要被扣除、缩小的那个对象的名称行**，再点击此按钮。计算为 `当前对象 = 当前对象 − 其他同类对象的并集`，沿其他对象的已有边界扣除；其他对象作为参考不被修改。若完全被其他同类对象覆盖，当前对象会移除；按 **Ctrl+Z** 可撤销。若扣除后出现分离区域，会保留成多个同类多边形。

只处理不同对象；两个图形的 **Group ID 相同且非空**时视为同一对象的分块，不互相扣除。不同对象应使用不同 Group ID，或都留空。已锁定的当前对象需要先解锁，参考对象可以保持锁定。

如果是同一堆体分次描出的同类多边形，通常适合合并或导出时取同类并集；如果是两个独立堆体的误重叠，可使用上述扣除按钮。语义分割需要导出成每像素一个类别的掩膜，同类并集不会重复计入；实例分割需要保持每个对象的独立范围和一致的可见区域标注规则。简单把各多边形面积相加会重复统计重叠面积，应统计并集。

### 不同类别的重叠

保存当前标注，关闭软件，再从桌面的“X-AnyLabeling（共边标注）”重新打开。右侧 **Shapes** 标题下方新增了一个扣除按钮。**单击需要修改的多边形名称文字，不要点左侧勾选框**；按钮会显示“从‘该类别’中扣除其他类别的重叠”。例如要保留“工程渣土”的边界，从“装修垃圾”中扣除重叠，就点“装修垃圾”这一行，再点按钮。工程渣土保持原样，装修垃圾沿其边界收缩。若与多个类别重叠，软件会让你选作为边界的类别。鼠标离开图片不影响这个选择。若扣错，按 **Ctrl+Z** 撤销。

如果准备按此方法处理新画的装修垃圾，先在顶部 **编辑** 中取消勾选“新区域覆盖旧多边形（共边）”，画好并保存装修垃圾后再点它的 Shapes 行和扣除按钮。否则默认的自动模式会在新区域完成时先裁剪工程渣土。若工程渣土已经被自动裁剪，需要先撤销该次新标注并重画。

列表左侧的勾选框只控制显示。需要修改的图形若已锁定，先解锁；作为边界的图形不会改变。不要右键点击列表行来执行扣除，因为原软件的右键用于切换锁定。

若图上明显压在一起却提示“未发现重叠”，先重启共边版再试。旧版按钮会跳过轮廓有自交的多边形；新版会先提取其中可用的区域再判断重叠。如果仍提示没有重叠，检查两条轮廓都已经完成、位于当前图片且类别名称不同。

若按钮已经显示“从‘建筑废料’中扣除…”却又提示“请先单击 Shapes 列表…”，说明列表记住的图形与画布当前图形不同步，并非没有点中。新版会自动找回当前画布中对应的多边形；同一类别有多个图形时，在 **Ctrl+J** 编辑模式下点选目标行，可让画布明确选中目标。

顶部 **编辑 → 新区域覆盖旧多边形（共边）** 默认勾选，可临时关闭。只处理**不同类别、未锁定的多边形**；矩形和同类多边形不会被自动裁剪。旧区域被切成几块时，会自动保留为多个同类别多边形。按 **Ctrl+Z** 可一次撤销新标注及其自动裁剪。

初次自动扣除仍只消除**已有的重叠**，不会自动跨过空白缝隙。请在按 **F** 确认新形状前让新轮廓稍微盖住旧轮廓。共边精修一次联动**一个相邻类别**；若同一形状还与第三类接壤，需要另选第三类再开启一次。已锁定的图形不能作为联动对象。撤销或切换图片时，联动精修会自动结束。
